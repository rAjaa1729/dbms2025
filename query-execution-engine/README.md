# Query Execution Engine

A continuation of [db362-indexes](../db362-indexes)'s DB362 engine: implementing
core relational operators using the iterator model — `Project` (with
duplicate elimination), `Filter`, and `HashJoin` — plus an open-ended
query optimizer.

## Status

The actual solution isn't in this repository. It was committed as a
nested clone of another repo, which git recorded as an empty submodule
reference rather than adding its files, so no clone of this repo —
including the one this was organized from — ever had the real source.

`docs/assignment-brief.pdf` is the original spec.
